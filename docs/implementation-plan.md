# 可执行闭环实现计划

本轮目标：让现有指令型 Skill 在复杂本地任务中具备可复现的规划、能力选择、证据核验和恢复支持，保留宿主负责理解目标、调用专业能力和执行修改的架构。

## 验收范围

- 可运行的标准库 CLI 随独立 Skill 包交付，无额外服务或依赖。
- 契约覆盖必要条件，任务依赖无环；状态能解释就绪、等待、失败、过期及下一步。
- 验证命令真正执行；记录命令、返回码、输出、耗时和输入/产物 SHA-256。不存在证据、文件变化、验证中变化、日志损坏均不能报通过。
- 任务恢复保留用户文件；结果未知的操作需核对才能解除；重复执行受显式预算限制。
- 能力选择先过滤不可用能力和硬条件，再用显式偏好排序，并解释候选结果。
- 端到端演示覆盖失败→修复→通过→用户修改→过期→重验；机器报告和便于阅读的报告来自同一状态。
- 回归测试、包检查、文档检查、ZIP 独立运行检查通过。204 项 Agent 行为目录与程序回归分开，不凭程序检查宣布全部行为验收完成。

## 实现边界

不把本地辅助工具描述为权限沙箱、后台服务、远程取消、自动获得外部连接或自动学习系统。验证命令由宿主审查并在已有授权范围内启动；CLI 不证明测试本身覆盖全部业务语义。状态为项目本地显式保存，不改全局技能、配置或偏好。

## 实施顺序

1. 实现契约校验、能力路由、版本证据及恢复 CLI。
2. 用正常、失败、文件变化、超时、未知操作等场景验证并修复缺陷。
3. 增加真实演示，更新 Skill 使用入口、双语说明、CI 与发布白名单。
4. 核验独立发布包，记录实际结果与剩余行为验证范围。

## 2026-10-22：工作台扩展已实现

已增加 13 个独立命令、项目偏好与任务覆盖、自然语言编辑、动态偏好图、调用履历与反馈、复盘导出、项目接续指引，以及 Codex 本机项目/近期聊天的快照桥接。可视前端采用深色星图和发光信息流，支持暂停和系统减少动态效果设置。实现路径与旧证据 CLI 并存，均由宿主驱动。

当前验收依据见[验证记录](validation.md)。尚未实现宿主事件的完整自动采集、原生项目实时订阅或跨项目自动学习。公开演示使用独立合成夹具；旧计划中的“无额外服务”指核心 CLI 不依赖常驻服务，工作台页面需要显式启动本机 HTTP 服务。

## 2026-10-22：Agent Harness 驾驶舱
