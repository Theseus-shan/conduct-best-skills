# 使用统计与偏好学习 · Stage 3 v1.1 / Stage 7

按需读取：能力路由使用获准历史记录时，或用户已启用统计并需要更新、查看、纠正、关闭、导出或清除记录时。此文件定义执行规则，不提供隐式后台采集器。

用户主动编辑的工作空间默认由[项目与任务偏好](preferences.md)管理，独立于本文件的可选统计。显式命中的可用能力默认加载和应用；不能把用户要求降成软排序。普通项目偏好不迁移到其他工作空间，也不因为配置偏好自动启用本文件的经验采集或跨项目迁移。

## 授权与数据

首次跨会话持久化前说明范围和用途，取得一次性同意并复用；未同意则只保留当前任务必要状态。统计、路由影响、软偏好学习、跨项目迁移可分别关闭。关闭项目统计即停止后续采集，清除的记录不再参与路由；清除本地统计不等于删除其他系统日志。

仅保存必要元数据；不默认收集完整 Prompt、对话、文件内容、工具参数/响应、个人资料和凭据。匿名化项目与任务标识，技能包本身不保存真实用户数据。运行记录、产物、统计事件、长期决策和用户偏好分别管理。

优先使用获准的用户可控本地存储。保留期建议为详细事件 90 天、聚合统计最多一年，可由用户调整；不是平台内置保证。若实际启用存储，明确清理执行机制，到期清理或聚合，不能仅写一条保留声明却无限保存。

## 事件与统计

对象：SKILL / TOOL / MCP / SUBAGENT。事件：DISCOVERED / SELECTED / LOADED / INVOKED / COMPLETED / FAILED / VERIFIED / USER_FEEDBACK。

事件字段：event_id、timestamp、task_id、session_id、work_unit_id、project_id、topic_id、task_type、capability_id、capability_type、capability_version、event_type、observation_type、outcome、source_reference、metrics。仅记录能可靠获得的字段；observation_type 为 OBSERVED / INFERRED / UNKNOWN，outcome 为 success / failure / partial / unknown。

按 event_id 去重，按能力 ID 与版本分别统计：

- Invocation Count：实际 INVOKED 次数；推荐、选中或重复加载不算调用。
- Task Usage Count：实际使用该能力的不同 task_id 数量。
- Verified Successful Task Count：实际参与且最终任务有明确验收成功证据的不同任务数；它仅表示关联，不证明因果贡献。
- Active Days：真实使用事件的不同日期，明确统计时区。
- Candidate Opportunity Count：确实可用且适用、进入真实比较的机会；分母缺失则不计算选择率。
- 近 7/30/90 天频率、操作失败率、已验证任务成功率和用户反馈分别报告；未知结局不冒充失败或成功。

注明覆盖范围、观测缺口和数据时效。接口不足时允许部分统计，不声称完整自动追踪。统计故障与核心任务隔离。

## 偏好路由

Explicit 与 Inferred 分开存储。一次选择不自动成为长期偏好，自动路由高频不能证明用户喜欢。

先 Hard Eligibility（适配性、硬约束、可用性、风险、验收），后 Soft Preference Ranking。优先级：当前请求 → 本次明确选择/拒绝 → 主动保存的有效偏好 → 专题证据 → 项目证据 → 符合条件的跨项目证据 → 一般频率。适用的局部显式偏好通常优先于宽泛偏好；实质冲突不能确定覆盖关系时协商。

软偏好考虑独立任务样本、任务相似性、反馈、验证结果、时效、观察质量和自动路由选择偏差；保留 INSUFFICIENT / EMERGING / SUPPORTED / STALE / REVOKED。阈值、衰减及影响上限须经实际校准，不声称随意参数最优；样本不足不报高置信度，新能力仍可参与比较。

## 有条件跨项目迁移

仅迁移获准的聚合能力适用性、效果、反馈和成本经验，不迁移原始材料、私密对话、研究假设、结论、操作授权或凭据。以下七项全部满足才可迁移：

1. 当前专题/项目局部证据不足或不具代表性。
2. 能力需求、任务类型、验收要求实质相似，不能只比较关键词。
3. 能力仍适用、可用且版本环境兼容。
4. 不与当前请求、显式偏好、契约及授权冲突。
5. 来源统计可信、未明显过时或严重偏倚。
6. 来源项目允许输出、目标项目允许接受，用户未关闭迁移。
7. 影响有界，仅辅助排序，不能单独决定高风险能力组合。

优先当前任务、专题、项目、项目内相关专题、其他项目同类任务，最后一般全局统计。匹配标为 HIGH / MEDIUM / LOW / NONE；LOW 仅辅助发现，NONE 不影响路由，标签不是成功概率。

保留无历史偏好的比较基线；出现负迁移时降低或停用其影响，支持只关闭迁移而保留本地学习。经验不能自动改全局 AGENTS.md 或已安装 Skill。
