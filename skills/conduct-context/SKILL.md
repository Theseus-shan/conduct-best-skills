# Conduct · 上下文核查

先读取[共享调用规则](../conduct-best-skills/references/command-scope.md)，再读取[本能力规范](../conduct-best-skills/references/stage-1-context.md)。相对路径以本文件位置解析；本入口依赖同级 `conduct-best-skills`，应安装完整 suite 包。缺失时明确报告依赖缺口，不搜索其他项目来拼接规范。

1. 读取用户指定对象与适用指令，区分事实、提案、假设及当前版本。
2. 交付可信上下文、缺口和下一步；不修改业务产物。

当前 prompt 的明确范围优先；本命令只负责上述工作。需要前置事实时做最少核查，不因加载共享规范自动启动七阶段全流程。只在用户明确要求组合步骤时继续相应后续能力。
